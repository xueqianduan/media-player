# LumiPlayer 本地视频字幕与音轨实现方案

复核日期 2026-11-20 · Android 首版 · 代码基线 `93446b8`

用户打开自带字幕或多条音轨的视频后，可以在「更多」→「字幕与音轨」中直接切换。「字幕」支持自动选择、指定轨道和关闭，「音轨」支持在多条可用音轨间切换。轨道来自当前视频，整个流程可以离线使用。首版验收内嵌文本字幕和多音轨。外挂字幕匹配、在线搜索、语音转字幕和字幕样式设置列入后续范围。

## 1. 现状与实现缺口

| 模块 | 已有能力 | 需要补齐 |
| --- | --- | --- |
| 播放引擎 | `MediaKitPlaybackEngine` 已持有 `Player` 和 `VideoController`，`media_kit` 提供轨道列表、选中状态和切换 API | `VideoPlaybackEngine` 未暴露轨道数据和操作，领域层及页面目前无法统一调用。 [引擎接口](../lib/features/player/domain/playback_engine.dart) · [引擎适配器](../lib/features/player/data/media_kit_engine.dart) |
| 播放会话 | `PlaybackSession` 管理打开文件、续播、队列切换、播放状态和资源释放 | 缺少当前视频的轨道快照、切换请求和切片后的状态清理。 [播放会话](../lib/features/player/domain/playback_session.dart) |
| 播放器 UI | 「更多」已有横竖屏共用的右侧面板，`VideoSurface` 复用 `media_kit_video` 的 `Video` | 缺轨道菜单、已选标记、无可用字幕提示和切换失败反馈。现有播放控件与字幕的摆放需要真机确认。 [播放器页面](../lib/features/player/presentation/player_page.dart) · [视频渲染层](../lib/features/player/data/media_kit_engine.dart) |
| 验证 | 已有 `PlaybackSession` 单元测试和可控的假引擎 | 补轨道状态和切片时序测试，并用真正包含多轨的样片验证字幕出字、配音变化及切换后的播放位置。 [现有会话测试](../test/unit/playback_session_test.dart) |

## 2. 首版交互与规则

| 场景 | 界面行为 |
| --- | --- |
| 首次打开或换片 | 使用引擎的自动选轨策略。媒体加载中显示「正在读取轨道」，成功加载后展示结果。手动选择仅作用于当前打开的视频。 |
| 有可用字幕 | 「字幕」列出「自动」「关闭」和可选轨道。点击后在当前播放位置应用，按确认后的选择显示勾选。 |
| 没有可用字幕 | 「字幕」显示「当前视频无可用字幕」。没有额外下载步骤。已压在画面里的文字会随视频画面播放。 |
| 有多条音轨 | 「音轨」列出「自动」和独立轨道。优先展示轨道标题和语言；同名轨道可加声道信息或序号。只有一条时显示当前音轨，采用只读状态。没有音轨时显示「当前视频无音轨」。 |
| 轨道缺少名称或语言 | 显示「字幕 1」「音轨 2」等可区分标签。以轨道 ID 识别选中项，文件中的语言和标题只用于展示。 |
| 切换失败或轨道已失效 | 保持或恢复到引擎可用的选轨状态，面板提示「切换失败，请重试」，当前视频继续按原来的播放或暂停状态运行。 |

## 3. 技术与模块设计

### 3.1 轨道接口与底层适配

- 沿用锁定的 `media_kit 1.2.6` 和 `media_kit_video 2.0.1`。在 `VideoPlaybackEngine` 增加轨道状态快照、变化订阅及字幕、音轨选择方法。领域状态包含读取状态、两类轨道列表、当前选择与操作反馈。普通轨道保存 ID、标题、语言及测试所需的编解码信息，自动和关闭用独立选项表达。页面通过领域对象访问轨道。 [依赖锁文件](../pubspec.lock) · [media_kit 轨道 API](https://pub.dev/packages/media_kit/versions/1.2.6#select-video-audio-or-subtitle-track)
- `MediaKitPlaybackEngine` 在媒体轨道就绪后从 `player.state.tracks` 取初始列表，结合 `player.stream.tracks` 更新，读取 `state.track` 和 `stream.track` 获取选轨状态。过滤库自带的 `auto`、`no` 项后再计算真实轨道数量。自动模式显示「自动」，语言和名称只按文件元数据呈现。显式选择用该文件当前列表里的原始 `AudioTrack` 或 `SubtitleTrack` 调用 `setAudioTrack` 或 `setSubtitleTrack`。恢复自动和关闭字幕分别使用 `auto()` 和 `SubtitleTrack.no()`。 [media_kit 轨道 API](https://pub.dev/packages/media_kit/versions/1.2.6#select-video-audio-or-subtitle-track)
- 在 Android 样片上核对实体轨道选择和实际生效的轨道。锁定版本会更新 Dart 侧选择状态，部分底层属性错误仅写入日志。实现时可在适配器内通过 mpv 的 `current-tracks/audio/id` 和 `current-tracks/sub/id` 核对指定轨道，关闭字幕时检查有效字幕轨已清除。把自动模式作为选择策略保存，自动选出的具体轨道可以随视频变化。 [mpv 轨道属性](https://mpv.io/manual/stable/#properties)
- 首版用 MKV 中的 SubRip 和 MP4 中的 `mov_text` 作为文本字幕验收基线。若遇到图片型 PGS、VobSub 或需保留复杂 ASS 样式的轨道，以样片验证渲染能力。确定当前渲染链路无法显示的轨道后，在界面标注「暂不支持」。检查随视频打开时由引擎自动载入的外部轨道，面板名称统一用「字幕」，保留引擎已经可用的播放行为。
- `player.open` 与选轨请求在适配器中按顺序执行。每次新开视频建立新的打开编号，先撤销旧轨道快照。用当前媒体解析完成后的引擎快照建立列表，再消费该次打开期间的轨道变化。打开编号负责拦截已经过期的请求和异步结果。底层事件本身没有媒体 ID，真机用连续换片验证 `media_kit` 重置轨道和发布新列表的顺序；如果检测到旧事件混入，就在原生适配器以当前媒体真正加载为边界再采样，不由页面按延时猜测。

### 3.2 会话控制与生命周期

- `PlaybackSession` 订阅轨道状态，通过独立的 `ValueNotifier` 更新面板。切换前再次检查媒体、打开编号和轨道 ID。加载中或同类切换请求尚未结束时暂时禁用本组选择。切换以引擎结果更新勾选，失败仅更新面板反馈。多次点击、换片和退出期间的旧请求须在真正调用引擎前被拒绝，迟到的完成通知也不得写入新视频的状态。
- 手动下一集、队列跳转和自动连播共用现有 `_openCurrent` 流程。进入新媒体时清空轨道和错误状态，并验证引擎的自动选轨是否已经复位。mpv 可能在轨道结构相近的文件之间保留显式选择，必要时由适配器在打开新媒体前恢复自动。选轨只更新正在使用的引擎轨道属性，继续使用原有播放位置、暂停状态、倍速和队列。关闭页面时取消订阅并释放监听状态。 [mpv 选轨行为](https://mpv.io/manual/stable/#track-selection)
- 同步更新 `_FailedEngine` 和 `_FakeEngine` 实现。失败引擎返回不可用状态，假引擎提供可延迟的轨道事件和切换结果，用来覆盖换片、退出及切换失败场景。 [失败引擎](../lib/features/player/presentation/player_page.dart) · [测试替身](../test/unit/playback_session_test.dart)

### 3.3 播放面板与字幕显示

- 在现有「更多」加入「字幕与音轨」入口，复用右侧面板的安全区、滚动和关闭逻辑。字幕、音轨分组展示，行内给出语言、名称和已选状态。加载、无可用轨道、仅一条音轨及失败分别有对应反馈。字幕关闭后立即清除屏幕上的字幕，切换回有效文字轨后按当前时间渲染。
- 优先使用现有 `Video` 自带的文本字幕渲染。根据竖屏、横屏和播放控制栏状态使用 `SubtitleViewConfiguration` 调整底部留白，真机检查长行、中文和视频缩放后是否被进度条遮住或被裁边。内嵌轨道通过现有视频读取授权访问，交付时无需增加 Android 权限和字幕服务依赖。 [media_kit 字幕显示配置](https://pub.dev/packages/media_kit/versions/1.2.6#customize-subtitles)

## 4. 实施顺序与每步交付

| 步骤 | 工作 | 交付成果与通过条件 |
| --- | --- | --- |
| 1. 验证样片与引擎 | 准备可合法使用的短 MKV 和 MP4 样片，包括双音轨、两条有明显文字差异的字幕，以及仅一条音轨且无字幕的对照样片。确认锁定版本读取到的轨道 ID、语言、编解码信息和字幕实际输出。 | **样片清单和 Android 验证记录。** 离线读取轨道，能在同一个播放器实例中切换两条音轨及文本字幕，关闭后不再显示字幕。记录实测版本和样片编码。 |
| 2. 接通引擎接口与播放会话 | 实现轨道状态、选择方法、媒体打开顺序及资源清理。补假引擎与会话回归测试。 | **可被 UI 调用的接口、引擎实现、单元测试。** 验证过滤虚拟轨道、暂停中选轨、失败恢复、换片复位、迟到事件和关闭时资源释放。现有续播和队列用例通过。 |
| 3. 接通手机端交互 | 接「字幕与音轨」面板、选中状态、无轨道提示与字幕安全区。 | **可点验的播放器页面和 Widget 测试。** 有轨道能切换，单音轨及无字幕状态清楚。中文长名称可区分，横竖屏能操作，关闭字幕后继续播放。 |
| 4. 真机回归与交付 | 用现有入口分别打开媒体库扫描的视频和导入的视频。测试离线、多轨、暂停、拖动、横竖屏、自动连播及退回重进。 | **Android 测试 APK 和验收记录。** 下表全部通过。记录支持的媒体格式及未通过的字幕编码，发布说明可据此准确描述范围。 |

## 5. 验收清单

| 编号 | 验收操作 | 通过标准 |
| --- | --- | --- |
| TR01 | 飞行模式下打开含中英文文本字幕的样片 | 面板列出真实轨道。切换后能看到对应语言，选择「关闭」清空字幕，再选回来能正常显示。 |
| TR02 | 在播放中切换两条容易区分的音轨 | 实际声音变化，进度继续，选中标记与切换结果一致。 |
| TR03 | 暂停后选轨，再拖动到另一段并继续播放 | 选轨时仍保持暂停，恢复后用所选音轨和字幕，进度从拖动的位置继续。 |
| TR04 | 打开无字幕、单音轨或标签缺失的样片 | 无字幕有明确提示，单音轨无多余切换选项，缺少标签时仍能区分不同轨道。 |
| TR05 | 切换字幕后跳到下一集，包含自动连播和快速换片 | 下一集只显示自己的轨道，按自动策略打开，旧选择及旧请求不会影响新视频。 |
| TR06 | 在横竖屏下播放带中文字幕的样片，显示或隐藏控制栏 | 面板触控正常，字幕清晰，主要控件和字幕正文可读。 |
| TR07 | 模拟选轨报错，并测试选轨尚未完成时退出播放页 | 失败反馈可见，视频仍能播放，退出后无异常回调或残留监听。 |

验收时先运行 `flutter test test/unit/playback_session_test.dart` 和新增的轨道面板 Widget 测试，再执行 `flutter analyze` 与 `flutter build apk --debug`。字幕是否实际出字、音轨是否真正改变，以及选轨期间播放是否连续，以 Android 真机结果为准。
