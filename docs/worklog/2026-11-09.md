## 二、今日踩坑

### 多选操作栏「点了没反应」——根因不是手势，是缺中文本地化

现象：收藏 / 分类 / 播放列表 / 更多 四个按钮按下有水波纹，但面板始终不出现。

排查过程走了弯路：

1. 先怀疑操作栏落在 `Scaffold.bottomNavigationBar` 里，底部安全区被清零、整条栏压在系统手势区导致抬手事件被取消 → 把操作栏挪进 body 的 Column 末尾，加 `SafeArea(minimum: 24)`，改 `onTapDown` 提前触发。**问题依旧**。
2. 写探针测试逐个点四个回调与四个面板，全部正常 → 代码链路本身没问题。
3. 真实根因：`app.dart` 声明了 `locale: Locale('zh','CN')` 和 `supportedLocales`，但**没有配 `localizationsDelegates`**。`MaterialLocalizations.of()` 直接抛异常，`showModalBottomSheet` 在创建阶段就失败。

为什么测试没抓到：`test/helpers/test_harness.dart` 里的 `_TestApp` 没有设置 locale，走英文默认，而英文资源是内置的，所以一路通过。

修复：`pubspec` 加 `flutter_localizations`，`app.dart` 补 `GlobalMaterialLocalizations` / `GlobalWidgetsLocalizations` / `GlobalCupertinoLocalizations` 三个 delegate；同时把 `onTapDown` 的权宜做法改回标准 `onTap`（保留去抖与圆形按压反馈）。

**教训**：声明了 locale 就必须同时提供对应语言的资源，否则框架断言会被"吞"成无声失败。「点了没反应」这类问题，先怀疑框架断言，再怀疑手势。
