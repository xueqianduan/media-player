## 用例

| 编号 | 场景 | 预期 | 结果 |
| --- | --- | --- | --- |
| T1 | A 接收、B 发送 1 个 10 MB 视频 | 自动进入详情，SHA-256 一致 | |
| T2 | 交换角色（A 发 B 收） | 同上 | |
| T3 | 多文件混合（视频 + 图片 + 文档 + 0 字节） | 逐个完成，空文件成功 | |
| T4 | 同名文件重传 | 保留旧文件，新文件带 (1) | |
| T5 | 错误指纹（手工改二维码一位） | 连接被拒绝并提示身份校验失败 | |
| T6 | 关闭蜂窝、断开外网 | 仍可配对传输 | |
| T7 | 等待码过期 | 页面自动换码，旧码连接失败 | |
| T8 | 传输中取消 | 未完成文件被清理，已完成保留 | |
| T9 | 传输中断网 | 任务失败，已完成文件可打开 | |
